# 如何使用

本文将介绍在安装完成MetaMystia后，您在游戏中应如何进行基本操作与联机。

如果您不熟悉电脑网络或“命令”这些概念，也不用担心，只要照着步骤操作，就可以和朋友成功连线游玩。

开始联机前，所有玩家都要安装MetaMystia，并先进入一次游戏主菜单。如果使用ResourceEx扩展内容，也应安装同一版本的资源包。

## 选择联机方式

MetaMystia支持两种联机方式：

| 方式       | 适合的情况                                          | 主要命令                             |
| ---------- | --------------------------------------------------- | ------------------------------------ |
| 服务器模式 | 大家不在同一个局域网，也不想配置组网工具            | `/mp play`、`/mp create`、`/mp join` |
| 局域网模式 | 大家在同一个局域网，或已经用Tailscale等工具组好网络 | `/mp start`、`/mp connect`           |

两种方式的游玩流程相同，只是创建和加入房间的步骤不同。

## 准备：设置玩家名

每名玩家按<kbd>/</kbd>打开命令输入框，再输入：

```text
/mp id PlayerName
```

`PlayerName`是显示给其他玩家的名字，可以换成自己的名字。名字不能包含空格，也不能和房间内其他玩家重复。不设置时会使用电脑名称。

## 服务器模式 {#server_mode}

### 创建房间

由一名玩家连接测试联机服务器并创建房间：

```text
/mp play
/mp create 4
```

`4`表示房间最多4人，包括创建房间的玩家，可以按实际人数修改。创建成功后，控制台会显示4位房间号，例如`AB20`。把房间号发给其他玩家。

### 加入房间

其他玩家输入：

```text
/mp play
/mp join AB20
```

把`AB20`换成实际的房间号，大小写均可。不知道房间号时，可以在连接服务器后输入`/mp rooms`查看服务器上的房间。

### 离开房间

输入`/mp leave`可以离开当前房间，但仍保持与服务器的连接，之后可以再创建或加入其他房间。创建房间的玩家离开时，房间会解散，其他玩家会退出房间，但仍连接在服务器上。

输入`/mp disconnect`会完全断开与服务器的连接。

## 局域网模式

### 第一步：设置房间人数

房间默认最多2人，包括房主。三人或更多人游玩时，房主先输入：

```text
/mp maxplayers 4
```

上面的`4`表示房间最多4人，可以按实际人数修改。

### 第二步：房主开房

房主输入：

```text
/mp start
```

执行`/mp start`后，房主需要把自己的IP地址发给其他玩家。如果大家不在同一个局域网，可先使用Tailscale、ZeroTier等组网工具，再发送组网工具显示的IP；也可以改用[服务器模式](#server_mode)。

### 第三步：其他玩家加入

每名加入者输入：

```text
/mp connect 房主IP
```

例如：

```text
/mp connect 192.168.1.10
```

连接后会自动进入房主的房间。房主退出时联机会结束，需要重新开房。

## 开始游玩

连接成功后，按<kbd>Enter</kbd>可以打开玩家列表。列表中会显示房主、其他玩家，以及大家当前正在进行的游戏流程。

> [!NOTE]
> 房间内所有玩家都处于主菜单或白天，且房主还没有结束白天时，其他玩家才能加入或重连。请在主菜单或白天让所有玩家到齐，再继续游戏。

- 白天：每个人使用自己的存档，各自进行白天活动。所有玩家结束白天后才会继续。
- 选店：所有玩家要选择相同的店铺和等级。
- 开店前：大家分别选择菜单、饮品和厨具；所有玩家确认后才会开始营业。
- 营业：可以分工做菜、取货、上菜和接待顾客。

有人中途离开时，剩下的玩家完成当前流程后会自动继续。如果开店前设置一直停在等待画面，房主确认自己的设置后可以输入：

```text
/mp continue prep
```

执行后所有玩家都会被视为已确认，直接开始营业。

## 聊天和玩家列表

以下是MetaMystia的默认按键。如果您修改过模组配置，请以自己的设置为准。

| 按键                        | 功能                                                 |
| --------------------------- | ---------------------------------------------------- |
| <kbd>T</kbd>                | 打开聊天输入框                                       |
| <kbd>/</kbd>                | 打开命令输入框                                       |
| <kbd>Enter</kbd>            | 输入框关闭时显示或隐藏玩家列表；输入框打开时发送内容 |
| <kbd>Esc</kbd>              | 关闭输入框                                           |
| <kbd>&#92;</kbd>            | 显示或隐藏左下角状态文字                             |
| <kbd>Tab</kbd>              | 补全命令                                             |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 查看以前输入过的命令                                 |

聊天时直接输入文字即可；以`/`开头的内容会被当作命令执行。玩家列表和聊天窗口可以拖动位置。

## 局域网模式下的网络连接

不方便配置网络时，可以直接使用[服务器模式](#server_mode)。

- 同一个Wi-Fi或局域网：使用房主的局域网IP。
- 不在同一局域网：可以使用Tailscale、ZeroTier等组网工具，把所有玩家加入同一个虚拟局域网。
- 房主有公网IP：可在防火墙和路由器中放行端口后直接连接。

MetaMystia默认使用`40815`端口。需要修改时，房主和其他玩家必须使用同一个端口：

```text
/mp start 50000
```

其他玩家使用以下任一种写法：

```text
/mp connect 192.168.1.10:50000
/mp connect 192.168.1.10 50000
```

一般玩家不需要修改IPv6设置。确实使用IPv6网络时，可在[常用命令](./commands.md)中查看相关命令。

## 连接不上怎么办

依次检查：

1. 所有人是否安装了相同版本的游戏和MetaMystia。
2. 是否都进入过一次主菜单，左下角能否看到MetaMystia状态文字。
3. 服务器模式下，是否都已用`/mp play`连接成功，房间号是否正确。
4. 局域网模式下，房主是否已经输入`/mp start`，其他玩家填写的IP和端口是否正确。
5. 房间人数是否已满，玩家名字是否重复或带有空格。
6. 房间内是否已有玩家进入开店前设置或开始营业，或房主已经结束白天。
7. 防火墙、路由器或组网工具是否阻止了连接。

输入`/mp status`可以查看当前连接状态。仍无法解决时，请查看[常见问题](./faq.md)。
