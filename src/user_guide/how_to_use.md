# 如何使用

本文将介绍在安装完成MetaMystia后，您在游戏中应如何进行基本操作与联机。

如果您不熟悉电脑网络或“命令”这些概念，也不用担心，只要照着步骤操作，就可以和朋友成功连线游玩。

开始联机前，所有玩家都要安装MetaMystia，并先进入一次游戏主菜单。如果使用ResourceEx扩展内容，也应安装同一版本的资源包。

## 第一步：设置房间人数

房间默认最多2人，包括房主。三人或更多人游玩时，房主先按<kbd>/</kbd>打开命令输入框，再输入：

```text
/mp maxplayers 4
```

上面的`4`表示房间最多4人，可以按实际人数修改。

## 第二步：房主开房

房主输入：

```text
/mp id HostName
/mp start
```

`HostName`是显示给其他玩家的名字，可以换成自己的名字。名字不能包含空格，也不能和房间内其他玩家重复。

执行`/mp start`后，房主需要把自己的IP地址发给其他玩家。如果大家不在同一个局域网，可先使用Tailscale、ZeroTier等组网工具，再发送组网工具显示的IP。

## 第三步：其他玩家加入

每名加入者输入：

```text
/mp id PlayerName
/mp connect 房主IP
```

例如：

```text
/mp id Aya
/mp connect 192.168.1.10
```

连接成功后，按<kbd>Enter</kbd>可以打开玩家列表。列表中会显示房主、其他玩家，以及大家当前正在进行的游戏流程。

> [!NOTE]
> 进入开店前设置画面后，以及夜间营业期间，不能加入或重连。请在主菜单或白天让所有玩家到齐，再继续游戏。

## 开始游玩

- 白天：每个人使用自己的存档，各自进行白天活动。所有玩家结束白天后才会继续。
- 选店：所有玩家要选择相同的店铺和等级。
- 开店前：大家分别选择菜单、饮品和厨具；所有玩家确认后才会开始营业。
- 营业：可以分工做菜、取货、上菜和接待顾客。

如果有人在白天结束或确认开店前设置后掉线，房主可根据游戏提示输入：

```text
/mp continue day
/mp continue prep
```

## 聊天和玩家列表

以下是MetaMystia的默认按键。如果您修改过模组配置，请以自己的设置为准。

| 按键                        | 功能                                                 |
| --------------------------- | ---------------------------------------------------- |
| <kbd>T</kbd>                | 打开聊天输入框                                       |
| <kbd>/</kbd>                | 打开命令输入框                                       |
| <kbd>Enter</kbd>            | 输入框关闭时显示或隐藏玩家列表；输入框打开时发送内容 |
| <kbd>Esc</kbd>              | 关闭输入框                                           |
| <kbd>&#92;</kbd>            | 显示或隐藏左下角状态文字                             |
| <kbd>Tab</kbd>              | 补全命令                                             |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 查看以前输入过的命令                                 |

聊天时直接输入文字即可；以`/`开头的内容会被当作命令执行。玩家列表和聊天窗口可以拖动位置。

## 不同网络下如何连接

- 同一个Wi-Fi或局域网：使用房主的局域网IP。
- 不在同一局域网：可以使用Tailscale、ZeroTier等组网工具，把所有玩家加入同一个虚拟局域网。
- 房主有公网IP：可在防火墙和路由器中放行端口后直接连接。

MetaMystia默认使用`40815`端口。需要修改时，房主和其他玩家必须使用同一个端口：

```text
/mp start 50000
```

其他玩家使用以下任一种写法：

```text
/mp connect 192.168.1.10:50000
/mp connect 192.168.1.10 50000
```

一般玩家不需要修改IPv6设置。确实使用IPv6网络时，可在[常用命令](./commands.md)中查看相关命令。

## 连接不上怎么办

依次检查：

1. 所有人是否安装了相同版本的游戏和MetaMystia。
2. 是否都进入过一次主菜单，左下角能否看到MetaMystia状态文字。
3. 如果游戏提示更新了Il2CppInterop补丁，是否关闭游戏并重新启动过一次。
4. 房主是否已经输入`/mp start`，其他玩家填写的IP和端口是否正确。
5. 房间人数是否已满，玩家名字是否重复或带有空格。
6. 房主是否已经进入开店前设置画面或开始营业。
7. 防火墙、路由器或组网工具是否阻止了连接。

输入`/mp status`可以查看当前连接状态。仍无法解决时，请查看[常见问题](./faq.md)。
