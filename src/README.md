# 项目介绍

[MetaMystia](https://github.com/MetaMystia/MetaMystia)是为游戏《[东方夜雀食堂](https://store.steampowered.com/app/1584090/)》制作的非官方Mod，主要提供多人联机和ResourceEx内容扩展功能。

如果您不熟悉“Mod”这个词，可以简单理解为：

> 一个安装在原版游戏上的“补丁式插件”，用来给游戏增加原本没有的新功能。

它的目标很简单：

> 让原本只能单人游玩的夜雀食堂，真正“热闹”起来。

通过MetaMystia，您可以和朋友在白天各自收集素材，晚上一起经营食堂；也可以安装ResourceEx资源包，体验新的角色、料理和剧情。

## 多人联机

《东方夜雀食堂》原版不能联机。安装MetaMystia后，一名玩家可以开房，其他玩家加入房间，共同完成白天活动和夜间营业流程。

联机可以通过测试联机服务器进行，也可以在局域网内直连。

房间默认最多2人，开房时可以调整人数上限，以进行三人及以上联机。

多人游玩时：

- 白天能看到其他玩家，每个人仍使用自己的存档，各自进行白天活动；
- 所有玩家结束白天后，一起选择店铺；
- 开店前可以分别选择菜单、饮品和厨具，所有玩家确认后开始营业；
- 营业时可以分工做菜、取货、上菜和接待顾客；
- 游戏内可以查看玩家列表、发送文字消息、切换角色外观；
- 房主可以修改人数上限或移出指定玩家。

## 皮肤系统

皮肤系统允许玩家使用游戏内已有角色和服装，也支持DLC、ResourceEx角色和服装，以及从皮肤站下载的网络皮肤。

每名玩家可以选择不同外观，选择结果会同步给房间内其他玩家。具体操作参见[皮肤系统](./user_guide/skin.md)。

## ResourceEx内容扩展

ResourceEx是MetaMystia提供的资源扩展功能，可以为游戏添加：

- 新的稀客角色和立绘；
- 新食材、料理和酒水；
- 新对话、羁绊任务和事件；
- 新商人、服装和物品；
- 资源包礼物邮箱和角色符卡。

普通玩家只需安装别人制作好的资源包。希望制作扩展内容的创作者，可以参见[ResourceEx资源扩展](./resource_ex/use_resource-ex.md)。

### 示例资源包

`MetaMystia-ResourceExample`是项目提供的示例资源包，加入了大妖精、小恶魔、芙兰朵露、八意永琳、神绮、秋姐妹、八云蓝、雪、舞等角色。

示例包还包含自定义食材、料理、酒水，以及新角色的对话、羁绊任务，商人和服装。部分角色剧情仍在制作，具体内容以当前发布的资源包为准。

## 当前限制

MetaMystia仍在开发中，目前需要注意：

- 所有玩家应使用相同的游戏版本和MetaMystia版本；
- 一起游玩ResourceEx内容时，所有玩家应安装同一版本的资源包；
- 部分剧情、挑战、试炼和料理对决尚未完整适配联机。

遇到尚未适配的剧情时，可以先断开联机，各自完成当天流程，再重新连接继续游玩。
