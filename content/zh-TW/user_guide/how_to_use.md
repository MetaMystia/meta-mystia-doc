# 如何使用

本文將介紹在安裝完成MetaMystia後，您在遊戲中應如何進行基本操作與連線。

如果您不熟悉電腦網路或「指令」這些概念，也不用擔心，只要照著步驟操作，就可以和朋友成功連線遊玩。

開始連線前，所有玩家都要安裝MetaMystia，並先進入一次遊戲主選單。如果使用ResourceEx擴充內容，也應安裝同一版本的資源包。

## 選擇連線方式

MetaMystia支援兩種連線方式：

| 方式         | 適合的情況                                            | 主要指令                             |
| ------------ | ----------------------------------------------------- | ------------------------------------ |
| 伺服器模式   | 大家不在同一個區域網路，也不想設定組網工具            | `/mp play`、`/mp create`、`/mp join` |
| 區域網路模式 | 大家在同一個區域網路，或已經用Tailscale等工具組好網路 | `/mp start`、`/mp connect`           |

兩種方式的遊玩流程相同，只是建立和加入房間的步驟不同。

## 準備：設定玩家名稱

每名玩家按<kbd>/</kbd>開啟指令輸入框，再輸入：

```text
/mp id PlayerName
```

`PlayerName`是顯示給其他玩家的名字，可以換成自己的名字。名字不能包含空格，也不能和房間內其他玩家重複。不設定時會使用電腦名稱。

## 伺服器模式 {#server_mode}

### 建立房間

由一名玩家連線測試連線伺服器並建立房間：

```text
/mp play
/mp create 4
```

`4`表示房間最多4人，包括建立房間的玩家，可以按實際人數修改。建立成功後，主控台會顯示4位房間號，例如`AB20`。把房間號發給其他玩家。

### 加入房間

其他玩家輸入：

```text
/mp play
/mp join AB20
```

把`AB20`換成實際的房間號，大小寫均可。不知道房間號時，可以在連線伺服器後輸入`/mp rooms`查看伺服器上的房間。

### 離開房間

輸入`/mp leave`可以離開目前房間，但仍保持與伺服器的連線，之後可以再建立或加入其他房間。建立房間的玩家離開時，房間會解散，其他玩家會退出房間，但仍連線在伺服器上。

輸入`/mp disconnect`會完全中斷與伺服器的連線。

## 區域網路模式

### 第一步：設定房間人數

房間預設最多2人，包括房主。三人以上遊玩時，房主先輸入：

```text
/mp maxplayers 4
```

上面的`4`表示房間最多4人，可以按實際人數修改。

### 第二步：房主開房

房主輸入：

```text
/mp start
```

執行`/mp start`後，房主需要把自己的IP位址發給其他玩家。如果大家不在同一個區域網路，可先使用Tailscale、ZeroTier等組網工具，再傳送組網工具顯示的IP；也可以改用[伺服器模式](#server_mode)。

### 第三步：其他玩家加入

每名加入者輸入：

```text
/mp connect 房主IP
```

例如：

```text
/mp connect 192.168.1.10
```

連線後會自動進入房主的房間。房主退出時連線會結束，需要重新開房。

## 開始遊玩

連線成功後，按<kbd>Enter</kbd>可以開啟玩家列表。列表中會顯示房主、其他玩家，以及大家目前正在進行的遊戲流程。

> [!NOTE]
> 房間內所有玩家都處於主選單或白天，且房主還沒有結束白天時，其他玩家才能加入或重新連線。請在主選單或白天讓所有玩家到齊，再繼續遊戲。

- 白天：每個人使用自己的存檔，各自進行白天活動。所有玩家結束白天後才會繼續。
- 選店：所有玩家要選擇相同的店鋪和等級。
- 開店前：大家分別選擇菜單、飲品和廚具；所有玩家確認後才會開始營業。
- 營業：可以分工做菜、取貨、上菜和接待顧客。

有人中途離開時，剩下的玩家完成目前流程後會自動繼續。如果開店前設定一直停在等待畫面，房主確認自己的設定後可以輸入：

```text
/mp continue prep
```

執行後所有玩家都會被視為已確認，直接開始營業。

## 聊天和玩家列表

以下是MetaMystia的預設按鍵。如果您修改過模組設定，請以自己的設定為準。

| 按鍵                        | 功能                                                 |
| --------------------------- | ---------------------------------------------------- |
| <kbd>T</kbd>                | 開啟聊天輸入框                                       |
| <kbd>/</kbd>                | 開啟指令輸入框                                       |
| <kbd>Enter</kbd>            | 輸入框關閉時顯示或隱藏玩家列表；輸入框開啟時送出內容 |
| <kbd>Esc</kbd>              | 關閉輸入框                                           |
| <kbd>&#92;</kbd>            | 顯示或隱藏左下角狀態文字                             |
| <kbd>Tab</kbd>              | 補完指令                                             |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 查看以前輸入過的指令                                 |

聊天時直接輸入文字即可；以`/`開頭的內容會被當作指令執行。玩家列表和聊天視窗可以拖曳位置。

## 區域網路模式下的網路連線

不方便設定網路時，可以直接使用[伺服器模式](#server_mode)。

- 同一個Wi-Fi或區域網路：使用房主的區域網路IP。
- 不在同一區域網路：可以使用Tailscale、ZeroTier等組網工具，把所有玩家加入同一個虛擬區域網路。
- 房主有公網IP：可在防火牆和路由器中放行連接埠後直接連線。

MetaMystia預設使用`40815`連接埠。需要修改時，房主和其他玩家必須使用同一個連接埠：

```text
/mp start 50000
```

其他玩家使用以下任一種寫法：

```text
/mp connect 192.168.1.10:50000
/mp connect 192.168.1.10 50000
```

一般玩家不需要修改IPv6設定。確實使用IPv6網路時，可在[常用指令](./commands.md)中查看相關指令。

## 連不上怎麼辦

依次檢查：

1. 所有人是否安裝了相同版本的遊戲和MetaMystia。
2. 是否都進入過一次主選單，左下角能否看到MetaMystia狀態文字。
3. 伺服器模式下，是否都已用`/mp play`連線成功，房間號是否正確。
4. 區域網路模式下，房主是否已經輸入`/mp start`，其他玩家填寫的IP和連接埠是否正確。
5. 房間人數是否已滿，玩家名字是否重複或帶有空格。
6. 房間內是否已有玩家進入開店前設定或開始營業，或房主已經結束白天。
7. 防火牆、路由器或組網工具是否阻擋了連線。

輸入`/mp status`可以查看目前連線狀態。仍無法解決時，請查看[常見問題](./faq.md)。

## 取得協助 {#get_help}

您可以透過[GitHub Issues](https://github.com/MetaMystia/MetaMystia/issues)回報問題。為了方便定位，請提供：

- 問題現象和操作步驟；
- 所有玩家的遊戲、MetaMystia、DLC和資源包版本；
- 錯誤畫面截圖；
- 所有玩家的`遊戲根目錄/BepInEx/LogOutput.log`；
- 使用的網路方式，例如同一區域網路、Tailscale或連接埠對應。

如果您使用管理工具，可附上工具匯出的診斷包：執行工具後在「選擇操作」頁選擇**匯出診斷包**，依提示完成匯出。匯出結束後，工具會顯示壓縮檔路徑，也可以點「開啟所在資料夾」直接定位。
