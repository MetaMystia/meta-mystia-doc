# 常用指令

按<kbd>/</kbd>開啟主控台。指令和參數之間用空格分隔；方括號表示可選參數，不需要原樣輸入。執行`/help`或直接執行`/mp`、`/skin`可以查看遊戲內說明。

## 連線

連線分為伺服器模式和區域網路模式，完整步驟參見[如何使用](./how_to_use.md)。

- 伺服器模式：先用`/mp play`連線測試連線伺服器，再用`/mp create`建立房間，或用`/mp join`加入房間。
- 區域網路模式：房主用`/mp start`在本機開房，其他玩家用`/mp connect`連線房主後會自動進入房間。

| 指令                           | 說明                                                                                                            |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `/mp play`                     | 連線測試連線伺服器`play.metamystia.net`，連接埠為`40815`                                                        |
| `/mp start [port]`             | 在本機建立區域網路房間；不填寫連接埠時預設使用`40815`                                                           |
| `/mp connect <address> [port]` | 連線房主或伺服器；支援`IP:連接埠`或把連接埠寫成第二個參數。連線區域網路房主時會自動進入其房間                   |
| `/mp rooms`                    | 列出目前伺服器上的房間，包括房間號、房主UID、人數和是否允許加入                                                 |
| `/mp create [count]`           | 在已連線的伺服器上建立並進入房間，房間號由伺服器分配；`count`是房間人數上限，不填寫時使用`/mp maxplayers`的設定 |
| `/mp join <room>`              | 按房間號加入房間；房間號是4位十六進位數，例如`AB20`，大小寫均可                                                 |
| `/mp leave`                    | 離開目前房間；在伺服器上會保持與伺服器的連線，在區域網路房間中會直接中斷                                        |
| `/mp stop`                     | 停止連線服務並關閉目前房間                                                                                      |
| `/mp restart`                  | 使用目前連接埠重新建立房間                                                                                      |
| `/mp disconnect`               | 中斷連線；房主執行時會讓所有加入者離開                                                                          |
| `/mp status`                   | 查看連線狀態、人數、所在場景和在線玩家                                                                          |
| `/mp id <id>`                  | 設定玩家ID，並把變更同步給房間內其他玩家                                                                        |
| `/mp maxplayers [count]`       | 查看或設定最大玩家數；人數包含房主，可設定為1–256，預設值為2。已在房間內時只有房主能修改                        |
| `/mp kick id <name>`           | 房主按玩家ID踢人                                                                                                |
| `/mp kick uid <uid>`           | 房主按玩家列表中的編號踢人                                                                                      |
| `/mp continue prep`            | 開店前設定一直在等待時，房主確認自己的設定後執行，所有玩家視為已確認並開始營業                                  |
| `/mp ipv6 enable`              | 房主允許透過IPv6位址加入，IPv4仍可使用                                                                          |
| `/mp ipv6 disable`             | 關閉IPv6連線                                                                                                    |

## 外觀

| 指令                                                           | 說明                                           |
| -------------------------------------------------------------- | ---------------------------------------------- |
| `/skin list`                                                   | 列出目前遊戲和ResourceEx提供的可用角色外觀     |
| `/skin set <characterId> <Default\|Explicit\|DLC> <skinIndex>` | 切換角色和服裝                                 |
| `/skin off`                                                    | 恢復遊戲預設角色外觀                           |
| `/skin net <name>`                                             | 從外觀站載入指定名稱的網路外觀                 |
| `/skin net refresh`                                            | 清除快取並重新下載目前網路外觀                 |
| `/skin net off`                                                | 關閉網路外觀並恢復預設外觀                     |
| `/skin rot on`                                                 | 強制允許角色貼圖旋轉                           |
| `/skin rot off`                                                | 強制禁止角色貼圖旋轉                           |
| `/skin rot clear`                                              | 清除旋轉覆寫，立即恢復外觀或遊戲的預設旋轉設定 |

## 資源包

| 指令                                 | 說明                                                       |
| ------------------------------------ | ---------------------------------------------------------- |
| `/resourceex list`                   | 列出成功載入和被拒絕的資源包                               |
| `/resourceex info <name>`            | 按ZIP檔名、`label`或顯示名稱查看資源包資訊和內容統計       |
| `/resourceex map list`               | 列出資源包註冊的白天地圖ID                                 |
| `/resourceex map goto <id> [marker]` | 進入指定白天地圖，可指定出生點；僅限單機白天自由活動時使用 |
| `/resourceex map back`               | 從資源包地圖返回進入前的地圖                               |

## 聊天和直播

不以`/`開頭的輸入會作為聊天訊息傳送。

直播隱私模式指令如下：

| 指令            | 說明                                     |
| --------------- | ---------------------------------------- |
| `/live`         | 立即切換為全開模式，隱藏玩家ID和聊天內容 |
| `/live partial` | 隱藏玩家ID並標出需要外部遮擋的聊天區域   |
| `/live full`    | 隱藏玩家ID和聊天內容                     |
| `/live off`     | 關閉直播隱私模式                         |

## 其他

| 指令                         | 說明                                     |
| ---------------------------- | ---------------------------------------- |
| `/help`                      | 列出已註冊指令                           |
| `/clear`                     | 清空主控台顯示內容                       |

| `/get currentactivemaplabel` | 顯示目前地圖名稱                         |
| `/get pos`                   | 顯示目前位置                             |
| `/link MetaMystia`           | 開啟MetaMystia倉庫                       |

`/debug`和其他`/call`子指令用於開發和診斷，可能直接改變遊戲狀態，不建議一般玩家使用。
