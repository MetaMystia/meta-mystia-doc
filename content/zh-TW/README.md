# 專案介紹

[MetaMystia](https://github.com/MetaMystia/MetaMystia)是為遊戲《[東方夜雀食堂](https://store.steampowered.com/app/1584090/)》製作的非官方Mod，主要提供多人連線與ResourceEx內容擴充功能。

如果您不熟悉「Mod」這個詞，可以簡單理解為：

> 一個安裝在原版遊戲上的「補丁式外掛」，用來為遊戲增加原本沒有的新功能。

它的目標很簡單：

> 讓原本只能單人遊玩的夜雀食堂，真正「熱鬧」起來。

透過MetaMystia，您可以和朋友在白天各自收集素材，晚上一起經營食堂；也可以安裝ResourceEx資源包，體驗新的角色、料理和劇情。

## 多人連線

《東方夜雀食堂》原版不能連線。安裝MetaMystia後，一名玩家可以開房，其他玩家加入房間，共同完成白天活動和夜間營業流程。

連線可以透過測試連線伺服器進行，也可以在區域網路內直連。

房間預設最多2人，開房時可以調整人數上限，以進行三人以上連線。

多人遊玩時：

- 白天能看到其他玩家，每個人仍使用自己的存檔，各自進行白天活動；
- 所有玩家結束白天後，一起選擇店鋪；
- 開店前可以分別選擇菜單、飲品和廚具，所有玩家確認後開始營業；
- 營業時可以分工做菜、取貨、上菜和接待顧客；
- 遊戲內可以查看玩家列表、傳送文字訊息、切換角色外觀；
- 房主可以修改人數上限或移出指定玩家。

## 外觀系統

外觀系統允許玩家使用遊戲內已有角色和服裝，也支援DLC、ResourceEx角色和服裝，以及從外觀站下載的網路外觀。

每名玩家可以選擇不同外觀，選擇結果會同步給房間內其他玩家。具體操作參見[外觀系統](./user_guide/skin.md)。

## ResourceEx內容擴充

ResourceEx是MetaMystia提供的資源擴充功能，可以為遊戲加入：

- 新的稀客角色和立繪；
- 新食材、料理和酒水；
- 新對話、羈絆任務和事件；
- 新商人、服裝和物品；
- 資源包禮物信箱和角色符卡。

一般玩家只需安裝別人製作好的資源包。希望製作擴充內容的創作者，可以參見[ResourceEx資源擴充](./resource_ex/use_resource-ex.md)。

### 範例資源包

`MetaMystia-ResourceExample`是專案提供的範例資源包，加入了大妖精、小惡魔、芙蘭朵露、八意永琳、神綺、秋姊妹、八雲藍、雪、舞等角色。

範例包還包含自訂食材、料理、酒水，以及新角色的對話、羈絆任務、商人和服裝。部分角色劇情仍在製作中，具體內容以目前發布的資源包為準。

## 目前限制

MetaMystia仍在開發中，目前請注意：

- 所有玩家應使用相同的遊戲版本和MetaMystia版本；
- 一起遊玩ResourceEx內容時，所有玩家應安裝相同版本的資源包；
- 部分劇情、挑戰、試煉和料理對決尚未完整支援連線。

遇到尚未支援的劇情時，可以先中斷連線，各自完成當天的流程，再重新連線繼續遊玩。
