# ResourceExリソース拡張

[ResourceEx](https://github.com/MetaMystia/MetaMystia/tree/main/src/MetaMystia.Mod/ResourceEx)はMetaMystiaに組み込まれたリソース拡張機能です。ゲーム起動時に`ResourceEx`フォルダ内のZIPリソースパックを読み込み、その設定と素材をロードします。

## 現在対応している内容

| 種類                 | 設定できる内容                                                                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| レア客               | 名前、図鑑の説明、立ち絵、ちびキャラの画像、昼の出現位置、営業への登場、資金、評価、雑談、好き嫌い、注文内容、絆会話                                       |
| 食材と料理           | 食材、料理、レシピ、飲み物、タグ、価格、レベル、アイコン、調理器具の種類                                                                                   |
| アイテム             | 名前、説明、アイコン。ギフト、商品、クエスト報酬、クエスト納品対象として使えます                                                                           |
| ストーリー           | 会話パッケージ、立ち絵、CGや背景、WAV音声、分岐、ジャンプ、終了アクション                                                                                  |
| クエストとイベント   | クエスト条件、報酬（アイテムやお金を含む）、後続クエスト、時間条件、イベントの発動、会話イベント                                                           |
| 商人                 | 歓迎や待機中の会話、価格倍率、在庫数、販売確率、商品リスト                                                                                                 |
| 衣装                 | アイコン、立ち絵、ちびキャラの画像、スキンインデックス、UIのオフセット                                                                                     |
| ギフトメールボックス | 配布するアイテム、ギフトのタイトル、受け取り時に再生される会話                                                                                             |
| スペルカード         | キャラクターのスペルカードの名前、説明、立ち絵、エフェクトパック、および持続効果のバフ名・説明・アイコン。スペルカードの効果はMetaMystiaに内蔵されています |
| 昼マップ             | マップのタイル、レイヤー、衝突、出現地点、カメラ、音楽。現在はプレビュー機能で、シングルプレイ時に`/resourceex map`でのみ入場できます                      |

## サンプルリソースパックの現状

サンプルパック（MetaMystia-ResourceExample）は[管理ツール](../user_guide/how_to_install.md#onclick_install)からインストールできます。リソースパックを作る場合は[サンプルパックのリポジトリ](https://github.com/MetaMystia/MetaMystia-ResourceExample)を参考にしてください。`ResourceEx.json`にすべてのサンプル内容が記載されています。

サンプルパックでは、キャラクター、会話、食材、料理、レシピ、飲み物、クエスト、イベント、商人、衣装、ギフトメールボックス、スペルカードなどの設定例を確認できます。大妖精、小悪魔、フランドール、八意永琳、神綺、秋姉妹、八雲藍、ユキ、マイなどのキャラクターが含まれます。マイと秋穣子にはすでに使用できるスペルカードがあり、一部のキャラクターには絆ストーリーがあります。残りの内容も今後追加されていきます。

サンプルパックはDLC1、DLC2、DLC4、DLC5に依存しています。いずれかが欠けているとサンプルパックは読み込まれません。詳しくは[DLC依存](#dlc_dependency)をご覧ください。

## リソースパックのインストール

1. リソースパックのZIPを`ゲームのルートフォルダ/ResourceEx`に直接置きます。解凍しないでください。
2. ゲームを起動します。フォルダが存在しない場合、MetaMystiaが自動で作成します。
3. `/resourceex list`を実行し、読み込みに成功したパックと拒否されたパックを確認します。
4. `/resourceex info <名前またはlabel>`を実行し、メタデータと内容の数を確認します。

ローダーが走査するのは`ResourceEx`直下の拡張子`.zip`のファイルだけです。サブフォルダは再帰的に走査しません。

## ZIPの構造

ZIPにはファイル名`ResourceEx.json`の設定ファイルが必須です。

```text
ExamplePack.zip
├─ResourceEx.json
└─assets
  ├─Character
  │ └─12000
  │   └─Portrait
  │     └─0.png
  └─Audio
    └─welcome.wav
```

## DLC依存 {#dlc_dependency}

リソースパックは`ResourceEx.json`の`packInfo.dependencies`で必要なDLCを宣言できます。例：

```json
"dependencies": ["CORE", "DLC2", "DLC5"]
```

- 宣言したDLCがすべてゲーム内で有効になっていないと、そのパックは拒否されます。`/resourceex list`で拒否されたパックと理由を確認できます。
- `dependencies`を宣言していないパックは本体のみに依存するとみなされ、常に読み込まれます。`CORE`は本体を表し、常に有効です。
- サンプルパックは`CORE`、`DLC1`、`DLC2`、`DLC4`、`DLC5`を宣言しています。

DLCが揃っているのに拒否される場合、または不足しているDLCが使いたい内容に影響しないと分かっている場合は、`ゲームのルートフォルダ/BepInEx/config/MetaMystia.cfg`を編集し、`[General]`セクションの`IgnoreDlcDependencyCheck`を`true`にしてゲームを再起動してください。有効にするとすべてのリソースパックが依存チェックを飛ばします。DLCが不足している内容は正しく表示されない、または未知の問題が起きる可能性があり、MetaMystiaの起動時にも警告が表示されます。

## 注文の設定

料理と飲み物の注文は、キャラクターの設定でそれぞれ宣言できます。ユーザー設定ファイル`BepInEx/config/MetaMystia.cfg`には3つのモードがあります：

- `ForceDisable`：強制的に無効；
- `FollowPackage`：リソースパック内の各リクエストの`enable`値に従う；
- `ForceEnable`：強制的に有効。

料理の注文`FoodRequestMode`の既定は`FollowPackage`、飲み物の注文`BevRequestMode`の既定は`ForceDisable`です。飲み物の注文コンテンツを作るときは、ユーザーに設定の調整が必要なことを伝えてください。

## IDと署名

ResourceExは現在、キャラクター、食材、料理、レシピ、飲み物、アイテム、衣装、昼マップ、スペルカード、バフのIDに統一的な検証を行っています：

- `8999`以下：ゲーム予約領域で、ResourceExでは使用禁止；
- `9000`から`1073741823`：管理領域で、有効なID範囲の宣言が必須。署名検証が有効な場合は署名も必要；
- `1073741824`から`2147483647`：自由領域で、署名は不要ですが、他のリソースパックとの衝突リスクは作成者が負います。

サンプルリソースパックは署名済みで`9000`から`12999`を使用しています。サードパーティの作成者はこの範囲をそのまま再利用しないでください。申請と署名の方法は[ID署名検証の仕組み](./why_add_signature_check.md)をご覧ください。

> [!CAUTION]
> 0〜11999の範囲のIDは避けてください。1000ごとに独立した制作区間として使うことで、衝突を減らせます。
>
> MetaMystia開発チームに希望する専用ID範囲を伝えて、リソースパックの一意性を確保することもできます。

## 会話の表示と発動

リソースパック内の会話パッケージは、クエスト、イベント、ギフトメールボックスから発動できます。

昼にゲーム本来の連携メニューを開くと、メニューの末尾に次の2項目が表示されます：

- `剧情回放(MetaMystia)`：ゲームのストーリーとResourceExの会話を再生します。ResourceExの会話は一度読んでからでないと再生できません；
- `资源包礼物邮箱`：リソースパックが設定したギフトを受け取ります。受け取り時に対応する会話が再生されます。ギフトが設定されていない場合はこの項目は使用できません。
