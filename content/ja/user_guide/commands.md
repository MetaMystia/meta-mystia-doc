# よく使うコマンド

<kbd>/</kbd>を押すとコンソールが開きます。コマンドと引数はスペースで区切ります。角括弧は省略可能な引数を示しており、そのまま入力する必要はありません。`/help`、または`/mp`や`/skin`だけを実行すると、ゲーム内ヘルプを確認できます。

## マルチプレイ

マルチプレイにはサーバーモードとLANモードがあります。詳しい手順は[使い方](./how_to_use.md)をご覧ください。

- サーバーモード：まず`/mp play`でテスト用マルチプレイサーバーに接続し、`/mp create`でルームを作成するか、`/mp join`でルームに参加します。
- LANモード：オーナーが`/mp start`でローカルにルームを立て、他のプレイヤーは`/mp connect`でオーナーに接続すると自動でルームに入ります。

| コマンド                       | 説明                                                                                                                                    |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `/mp play`                     | テスト用マルチプレイサーバー`play.metamystia.net`に接続します。ポートは`40815`です                                                      |
| `/mp start [port]`             | ローカルにLANルームを作成します。ポートを省略すると既定で`40815`を使用                                                                  |
| `/mp connect <address> [port]` | オーナーまたはサーバーに接続します。`IP:ポート`またはポートを2番目の引数として指定でき、LANのオーナーに接続すると自動でルームに入ります |
| `/mp rooms`                    | 現在のサーバー上のルーム一覧を表示します（ルーム番号、オーナーのUID、人数、参加可否を含む）                                             |
| `/mp create [count]`           | 接続済みのサーバーでルームを作成して入ります。ルーム番号はサーバーが割り当て、`count`は人数上限で、省略時は`/mp maxplayers`の設定を使用 |
| `/mp join <room>`              | ルーム番号でルームに参加します。ルーム番号は`AB20`のような4桁の16進数で、大文字と小文字はどちらでも構いません                           |
| `/mp leave`                    | 現在のルームから退出します。サーバー上では接続を維持し、LANルームではそのまま切断されます                                               |
| `/mp stop`                     | マルチプレイサービスを停止し、現在のルームを閉じます                                                                                    |
| `/mp restart`                  | 現在のポートでルームを作り直します                                                                                                      |
| `/mp disconnect`               | 接続を切断します。オーナーが実行すると参加者全員が退出します                                                                            |
| `/mp status`                   | 接続状態、人数、現在のシーン、オンラインプレイヤーを表示します                                                                          |
| `/mp id <id>`                  | プレイヤーIDを設定し、変更をルーム内の他のプレイヤーに同期します                                                                        |
| `/mp maxplayers [count]`       | 最大プレイヤー数を表示または設定します。人数にはオーナーを含み、1〜256で設定でき、既定は2です。ルーム内ではオーナーのみ変更できます     |
| `/mp kick id <name>`           | オーナーがプレイヤーIDでキックします                                                                                                    |
| `/mp kick uid <uid>`           | オーナーがプレイヤー一覧の番号でキックします                                                                                            |
| `/mp continue prep`            | 開店前設定が待機したままのとき、オーナーが自分の設定を確認して実行すると、全員が確認済みとして営業が始まります                          |
| `/mp ipv6 enable`              | オーナーがIPv6アドレスでの参加を許可します。IPv4も引き続き使用可能                                                                      |
| `/mp ipv6 disable`             | IPv6接続をオフにします                                                                                                                  |

## スキン

| コマンド                                                       | 説明                                                             |
| -------------------------------------------------------------- | ---------------------------------------------------------------- |
| `/skin list`                                                   | 現在のゲームとResourceExで利用できるキャラクタースキンを一覧表示 |
| `/skin set <characterId> <Default\|Explicit\|DLC> <skinIndex>` | キャラクターと衣装を切り替え                                     |
| `/skin off`                                                    | ゲーム既定のキャラクター外見に戻す                               |
| `/skin net <name>`                                             | スキンサイトから指定名のオンラインスキンを読み込む               |
| `/skin net refresh`                                            | キャッシュを消して現在のオンラインスキンを再ダウンロード         |
| `/skin net off`                                                | オンラインスキンをオフにして既定の外見に戻す                     |
| `/skin rot on`                                                 | キャラクターの立ち絵の回転を強制的に許可                         |
| `/skin rot off`                                                | キャラクターの立ち絵の回転を強制的に禁止                         |
| `/skin rot clear`                                              | 回転の上書きを解除し、スキンまたはゲーム既定の回転設定に戻す     |

## リソースパック

| コマンド                             | 説明                                                                               |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| `/resourceex list`                   | 読み込みに成功したリソースパックと拒否されたリソースパックを一覧表示               |
| `/resourceex info <name>`            | ZIPファイル名、`label`、または表示名でパックの情報と内容の統計を確認               |
| `/resourceex map list`               | リソースパックが登録した昼マップのIDを一覧表示                                     |
| `/resourceex map goto <id> [marker]` | 指定した昼マップに入る。出現地点も指定可能。シングルプレイの昼の自由行動時のみ使用 |
| `/resourceex map back`               | リソースパックのマップから入る前のマップに戻る                                     |

## チャットと配信

`/`で始まらない入力はチャットメッセージとして送信されます。

配信プライバシーモードのコマンドは次のとおりです：

| コマンド        | 説明                                                         |
| --------------- | ------------------------------------------------------------ |
| `/live`         | すぐに全開モードに切り替え、プレイヤーIDとチャット内容を隠す |
| `/live partial` | プレイヤーIDを隠し、外部で隠す必要があるチャット領域を表示   |
| `/live full`    | プレイヤーIDとチャット内容を隠す                             |
| `/live off`     | 配信プライバシーモードをオフにする                           |

## その他

| コマンド                     | 説明                                                     |
| ---------------------------- | -------------------------------------------------------- |
| `/help`                      | 登録済みコマンドを一覧表示                               |
| `/clear`                     | コンソールの表示内容を消去                               |
| `/whereami`                  | 昼のシーンで現在のマップと座標を表示                     |
| `/get currentactivemaplabel` | 現在のマップ名を表示                                     |
| `/get pos`                   | 現在位置を表示                                           |
| `/link MetaMystia`           | MetaMystiaリポジトリを開く                               |
| `/link Izakaya`              | 東方夜雀食堂のアシスタントを開く                         |
| `/call try_close_izakaya`    | 閉店処理が止まったとき、ローカルの営業を強制終了してみる |

`/debug`およびその他の`/call`サブコマンドは開発と診断用です。ゲームの状態を直接変更することがあるため、一般プレイヤーにはおすすめしません。
