# 使い方

このページでは、MetaMystiaをインストールした後に行う基本的な操作と、マルチプレイの進め方を説明します。

パソコンのネットワークや「コマンド」といった言葉に馴染みがなくても心配いりません。手順どおりに進めれば、友達と一緒に遊べるようになります。

始める前に、全員がMetaMystiaをインストールし、一度はゲームのメインメニューに入っている必要があります。ResourceExのコンテンツを使う場合は、全員が同じバージョンのリソースパックをインストールしてください。

## 接続方法の選択

MetaMystiaのマルチプレイには2つの方法があります：

| 方法           | 向いている状況                                               | 主なコマンド                         |
| -------------- | ------------------------------------------------------------ | ------------------------------------ |
| サーバーモード | 同じLANにいない、ネットワークツールの設定もしたくない        | `/mp play`、`/mp create`、`/mp join` |
| LANモード      | 同じLANにいる、またはTailscaleなどでネットワークを組んである | `/mp start`、`/mp connect`           |

どちらも遊び方は同じで、ルームの作成と参加の手順だけが異なります。

## 準備：プレイヤー名の設定

全員が<kbd>/</kbd>を押してコマンド入力欄を開き、次を入力します：

```text
/mp id PlayerName
```

`PlayerName`は他のプレイヤーに表示される名前です。自分の名前に置き換えてください。名前に空白は使えず、ルーム内の他のプレイヤーと重複してもいけません。設定しない場合はコンピューター名が使われます。

## サーバーモード {#server_mode}

### ルームの作成

1人がテスト用マルチプレイサーバーに接続してルームを作成します：

```text
/mp play
/mp create 4
```

`4`はルームの上限人数で、作成したプレイヤーも含みます。実際の人数に合わせて変更してください。作成に成功すると、コンソールに`AB20`のような4文字のルーム番号が表示されます。他のプレイヤーにこの番号を伝えてください。

### ルームへの参加

他のプレイヤーは次を入力します：

```text
/mp play
/mp join AB20
```

`AB20`を実際のルーム番号に置き換えてください。大文字と小文字はどちらでも構いません。番号が分からない場合は、サーバーに接続した後で`/mp rooms`を入力するとサーバー上のルームを確認できます。

### ルームからの退出

`/mp leave`を入力すると現在のルームから退出できますが、サーバーとの接続は維持されるので、その後また別のルームを作成したり参加したりできます。作成者が退出するとルームは解散し、他のプレイヤーはルームから出ますが、サーバーには接続したままです。

`/mp disconnect`を入力するとサーバーとの接続を完全に切断します。

## LANモード

### ステップ1：人数の上限を設定する

ルームは既定で最大2人（オーナーを含む）です。3人以上で遊ぶ場合、オーナーは次を入力します：

```text
/mp maxplayers 4
```

上の`4`はルームの上限人数です。実際の人数に合わせて変更してください。

### ステップ2：オーナーがルームを立てる

オーナーは次を入力します：

```text
/mp start
```

`/mp start`を実行したら、オーナーは自分のIPアドレスを他のプレイヤーに伝えます。同じLANにいない場合は、まずTailscaleやZeroTierなどのネットワークツールを導入し、そのツールに表示されるIPを伝えてください。代わりに[サーバーモード](#server_mode)を使うこともできます。

### ステップ3：他のプレイヤーが参加する

参加するプレイヤーはそれぞれ次を入力します：

```text
/mp connect オーナーのIP
```

例：

```text
/mp connect 192.168.1.10
```

接続するとオーナーのルームに自動で入ります。オーナーが終了するとマルチプレイは終わるので、ルームを立て直す必要があります。

## 遊び方

接続に成功したら、<kbd>Enter</kbd>を押すとプレイヤー一覧が開きます。一覧にはオーナー、他のプレイヤー、そして各自が今どの進行段階にいるかが表示されます。

> [!NOTE]
> ルーム内の全員がメインメニューまたは昼の間にいて、オーナーがまだ昼を終えていないときだけ、他のプレイヤーは参加または再接続できます。メインメニューか昼のうちに全員を揃えてから進めてください。

- 昼：各自のセーブデータを使い、それぞれで昼の活動を進めます。全員が昼を終えてから次に進みます。
- 店選び：全員が同じ店と同じレベルを選ぶ必要があります。
- 開店前：各自がメニュー、飲み物、調理器具を選びます。全員が確認してから営業が始まります。
- 営業：料理、食材の取り込み、配膳、接客を分担できます。

途中で誰かが抜けた場合、残ったプレイヤーが現在の進行を終えると自動で続行します。開店前の設定が待機画面のまま進まない場合は、オーナーが自分の設定を確認してから次を入力します：

```text
/mp continue prep
```

実行すると全員が確認済みと見なされ、そのまま営業が始まります。

## チャットとプレイヤー一覧

以下はMetaMystiaの既定キーです。Modの設定を変更している場合は、ご自身の設定が優先されます。

| キー                        | 機能                                                                      |
| --------------------------- | ------------------------------------------------------------------------- |
| <kbd>T</kbd>                | チャット入力欄を開く                                                      |
| <kbd>/</kbd>                | コマンド入力欄を開く                                                      |
| <kbd>Enter</kbd>            | 入力欄が閉じているときはプレイヤー一覧の表示/非表示、開いているときは送信 |
| <kbd>Esc</kbd>              | 入力欄を閉じる                                                            |
| <kbd>&#92;</kbd>            | 左下のステータス文字の表示/非表示                                         |
| <kbd>Tab</kbd>              | コマンドを補完する                                                        |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 以前に入力したコマンドを参照する                                          |

チャットではそのまま文字を入力してください。`/`で始まる内容はコマンドとして実行されます。プレイヤー一覧とチャットウィンドウはドラッグで位置を移動できます。

## LANモードでのネットワーク接続

ネットワークの設定が面倒な場合は、[サーバーモード](#server_mode)をそのまま使えます。

- 同じWi-Fi・LAN内：オーナーのLAN内IPを使います。
- 別のネットワーク：TailscaleやZeroTierなどを使い、全員を同じ仮想LANに参加させます。
- オーナーがグローバルIPを持つ場合：ファイアウォールとルーターでポートを開放すれば直接接続できます。

MetaMystiaは既定で`40815`ポートを使います。変更する場合、オーナーと他のプレイヤー全員が同じポートを使う必要があります：

```text
/mp start 50000
```

他のプレイヤーは次のどちらかの形式で入力します：

```text
/mp connect 192.168.1.10:50000
/mp connect 192.168.1.10 50000
```

通常はIPv6設定を変更する必要はありません。実際にIPv6ネットワークを使う場合は、[よく使うコマンド](./commands.md)で関連コマンドを確認してください。

## 接続できないときは

順に確認してください：

1. 全員が同じバージョンのゲームとMetaMystiaをインストールしているか。
2. 全員が一度はメインメニューに入り、左下にMetaMystiaのステータス文字が見えるか。
3. サーバーモードでは、全員が`/mp play`で接続に成功し、ルーム番号が正しいか。
4. LANモードでは、オーナーが`/mp start`を実行済みで、他のプレイヤーが入力したIPとポートが正しいか。
5. ルームの人数が上限に達していないか、名前が重複していたり空白を含んでいたりしないか。
6. ルーム内ですでに誰かが開店前の設定に入っている、営業を開始している、またはオーナーが昼を終えていないか。
7. ファイアウォール、ルーター、ネットワークツールが接続を妨げていないか。

`/mp status`を入力すると現在の接続状態を確認できます。それでも解決しない場合は[よくある質問](./faq.md)をご覧ください。

## サポートを受ける {#get_help}

問題は[GitHub Issues](https://github.com/MetaMystia/MetaMystia/issues)で報告できます。原因を特定しやすくするため、次の情報をご提供ください：

- 問題の症状と操作手順；
- 全員のゲーム、MetaMystia、DLC、リソースパックのバージョン；
- エラー画面のスクリーンショット；
- 全員の`ゲームのルートフォルダ/BepInEx/LogOutput.log`；
- 接続方法（同じLAN、Tailscale、ポート開放など）。

管理ツールを使っている場合は、ツールが出力する診断パッケージを添付できます。ツールを実行し、「操作を選択」ページで**診断パッケージを出力**を選び、案内に従って出力してください。出力が終わると圧縮ファイルのパスが表示され、「フォルダーを開く」で直接開くこともできます。
