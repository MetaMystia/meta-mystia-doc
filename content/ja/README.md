# プロジェクト紹介

[MetaMystia](https://github.com/MetaMystia/MetaMystia)は、ゲーム『[東方夜雀食堂](https://store.steampowered.com/app/1584090/)』向けの非公式Modで、主にマルチプレイとResourceExによるコンテンツ拡張を提供します。

「Mod」という言葉に馴染みがない方は、次のように考えてください：

> 元のゲームにインストールする「パッチのようなプラグイン」で、ゲームになかった新機能を追加します。

その目的はシンプルです：

> シングルプレイ専用だった夜雀食堂を、本当に「賑やか」にすること。

MetaMystiaを使えば、昼は友達とそれぞれ素材を集め、夜は一緒に食堂を経営できます。ResourceExのリソースパックをインストールすれば、新しいキャラクターや料理、ストーリーも楽しめます。

## マルチプレイ

『東方夜雀食堂』は元々マルチプレイに対応していません。MetaMystiaをインストールすると、1人がルームを立てて他のプレイヤーが参加し、昼の活動と夜の営業を一緒に進められます。

マルチプレイはテスト用マルチプレイサーバー経由でも、LAN内での直接接続でも行えます。

ルームは既定で最大2人で、ルームを立てるときに人数上限を変更して3人以上でも遊べます。

一緒に遊ぶとき：

- 昼は他のプレイヤーの姿が見えます。セーブデータは各自のものを使い、昼の活動もそれぞれで進めます；
- 全員が昼を終えると、一緒に店を選びます；
- 開店前にメニュー、飲み物、調理器具をそれぞれ選び、全員が確認すると営業が始まります；
- 営業中は料理を作る、食材を取りに行く、配膳する、接客するなどの役割を分担できます；
- ゲーム内でプレイヤー一覧の表示、テキストメッセージの送信、キャラクターの見た目の切り替えができます；
- オーナーは人数上限の変更や特定プレイヤーの退出ができます。

## スキンシステム

スキンシステムでは、ゲーム内のキャラクターと衣装のほか、DLCやResourceExのキャラクター・衣装、スキンサイトからダウンロードしたオンラインスキンも使用できます。

プレイヤーごとに違う見た目を選べ、選択結果はルーム内の全員に同期されます。詳しい操作は[スキンシステム](./user_guide/skin.md)を参照してください。

## ResourceExコンテンツ拡張

ResourceExはMetaMystiaが提供するリソース拡張機能で、ゲームに以下を追加できます：

- 新しいレア客と立ち絵；
- 新しい食材、料理、飲み物；
- 新しい会話、絆クエスト、イベント；
- 新しい商人、衣装、アイテム；
- リソースパックのギフトメールボックスとキャラクターのスペルカード。

一般プレイヤーは、誰かが作ったリソースパックをインストールするだけで使えます。自分でコンテンツを作りたい方は[ResourceExリソース拡張](./resource_ex/use_resource-ex.md)を参照してください。

### サンプルのリソースパック

`MetaMystia-ResourceExample`はプロジェクトが提供するサンプルのリソースパックで、大妖精、小悪魔、フランドール、八意永琳、神綺、秋姉妹、八雲藍、ユキ、マイなどのキャラクターを追加します。

サンプルパックには独自の食材、料理、飲み物のほか、新キャラクターの会話、絆クエスト、商人、衣装も含まれます。一部キャラクターのストーリーはまだ制作中で、具体的な内容は現在公開されているリソースパックが基準です。

## 現在の制限

MetaMystiaはまだ開発中です。現在は以下にご注意ください：

- すべてのプレイヤーが同じゲームバージョンとMetaMystiaバージョンを使用する必要があります；
- ResourceExのコンテンツを一緒に遊ぶ場合、全員が同じバージョンのリソースパックをインストールしてください；
- 一部のストーリー、チャレンジ、試練、料理対決はまだマルチプレイに完全対応していません。

未対応のストーリーに遭遇した場合は、いったんマルチプレイを切断し、その日の流れを各自で進めてから再接続して続けられます。
