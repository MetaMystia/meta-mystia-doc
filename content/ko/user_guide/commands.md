# 자주 쓰는 명령어

<kbd>/</kbd>를 누르면 콘솔이 열립니다. 명령어와 인수는 공백으로 구분하며, 대괄호는 선택 인수를 뜻하므로 그대로 입력할 필요는 없습니다. `/help`를 실행하거나 `/mp`, `/skin`만 실행해도 게임 내 도움말을 볼 수 있습니다.

## 멀티플레이

멀티플레이는 서버 모드와 LAN 모드가 있습니다. 전체 절차는 [사용 방법](./how_to_use.md)을 참고하세요.

- 서버 모드: 먼저 `/mp play`로 테스트 멀티플레이 서버에 접속한 뒤 `/mp create`로 방을 만들거나 `/mp join`으로 참가합니다.
- LAN 모드: 방장이 `/mp start`로 로컬에 방을 열고, 다른 플레이어는 `/mp connect`로 방장에게 접속하면 자동으로 방에 들어갑니다.

| 명령어                         | 설명                                                                                                                                          |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `/mp play`                     | 테스트 멀티플레이 서버 `play.metamystia.net`에 접속합니다. 포트는 `40815`입니다                                                               |
| `/mp start [port]`             | 로컬에 LAN 방을 만듭니다. 포트를 생략하면 기본값 `40815` 사용                                                                                 |
| `/mp connect <address> [port]` | 방장 또는 서버에 접속합니다. `IP:포트` 또는 두 번째 인수로 포트 지정 가능. LAN 방장에게 접속하면 자동으로 방에 들어갑니다                     |
| `/mp rooms`                    | 현재 서버의 방 목록을 표시합니다(방 번호, 방장 UID, 인원, 참가 가능 여부 포함)                                                                |
| `/mp create [count]`           | 접속한 서버에서 방을 만들어 들어갑니다. 방 번호는 서버가 할당하며, `count`는 인원 상한으로 생략 시 `/mp maxplayers` 설정을 사용               |
| `/mp join <room>`              | 방 번호로 방에 참가합니다. 방 번호는 `AB20` 같은 4자리 16진수이며 대소문자 모두 가능                                                          |
| `/mp leave`                    | 현재 방에서 나갑니다. 서버에서는 접속이 유지되고, LAN 방에서는 바로 연결이 끊어집니다                                                         |
| `/mp stop`                     | 멀티플레이 서비스를 중지하고 현재 방을 닫습니다                                                                                               |
| `/mp restart`                  | 현재 포트로 방을 다시 만듭니다                                                                                                                |
| `/mp disconnect`               | 연결을 끊습니다. 방장이 실행하면 모든 참가자가 나갑니다                                                                                       |
| `/mp status`                   | 연결 상태, 인원, 현재 장면, 온라인 플레이어를 표시합니다                                                                                      |
| `/mp id <id>`                  | 플레이어 ID를 설정하고 변경 사항을 방 안의 다른 플레이어에게 동기화합니다                                                                     |
| `/mp maxplayers [count]`       | 최대 플레이어 수를 확인/설정합니다. 인원에 방장이 포함되고 1–256으로 설정할 수 있으며 기본값은 2입니다. 방 안에서는 방장만 변경할 수 있습니다 |
| `/mp kick id <name>`           | 방장이 플레이어 ID로 추방합니다                                                                                                               |
| `/mp kick uid <uid>`           | 방장이 플레이어 목록의 번호로 추방합니다                                                                                                      |
| `/mp continue prep`            | 개점 전 설정이 계속 대기 중일 때 방장이 자신의 설정을 확인한 뒤 실행하면, 모든 플레이어가 확인한 것으로 처리되어 영업이 시작됩니다            |
| `/mp ipv6 enable`              | 방장이 IPv6 주소로 참가를 허용합니다. IPv4도 계속 사용 가능                                                                                   |
| `/mp ipv6 disable`             | IPv6 연결을 끕니다                                                                                                                            |

## 스킨

| 명령어                                                         | 설명                                                            |
| -------------------------------------------------------------- | --------------------------------------------------------------- |
| `/skin list`                                                   | 현재 게임과 ResourceEx에서 사용할 수 있는 캐릭터 스킨 목록 표시 |
| `/skin set <characterId> <Default\|Explicit\|DLC> <skinIndex>` | 캐릭터와 의상 전환                                              |
| `/skin off`                                                    | 게임 기본 캐릭터 외형으로 복원                                  |
| `/skin net <name>`                                             | 스킨 사이트에서 지정한 이름의 온라인 스킨을 불러옴              |
| `/skin net refresh`                                            | 캐시를 지우고 현재 온라인 스킨을 다시 다운로드                  |
| `/skin net off`                                                | 온라인 스킨을 끄고 기본 외형으로 복원                           |
| `/skin rot on`                                                 | 캐릭터 일러스트 회전을 강제로 허용                              |
| `/skin rot off`                                                | 캐릭터 일러스트 회전을 강제로 금지                              |
| `/skin rot clear`                                              | 회전 덮어쓰기를 지우고 스킨 또는 게임 기본 회전 설정으로 복원   |

## 리소스 팩

| 명령어                               | 설명                                                                                         |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| `/resourceex list`                   | 성공적으로 로드된 리소스 팩과 거부된 리소스 팩 목록 표시                                     |
| `/resourceex info <name>`            | ZIP 파일 이름, `label`, 표시 이름으로 팩 정보와 콘텐츠 통계 확인                             |
| `/resourceex map list`               | 리소스 팩이 등록한 낮 맵 ID 목록 표시                                                        |
| `/resourceex map goto <id> [marker]` | 지정한 낮 맵으로 이동하며 시작 지점도 지정할 수 있습니다. 싱글 플레이 낮 자유 활동 때만 사용 |
| `/resourceex map back`               | 리소스 팩 맵에서 들어가기 전 맵으로 돌아갑니다                                               |

## 채팅과 방송

`/`로 시작하지 않는 입력은 채팅 메시지로 전송됩니다.

방송 프라이버시 모드 명령어는 다음과 같습니다:

| 명령어          | 설명                                                            |
| --------------- | --------------------------------------------------------------- |
| `/live`         | 즉시 전체 공개 모드로 전환해 플레이어 ID와 채팅 내용을 숨깁니다 |
| `/live partial` | 플레이어 ID를 숨기고 외부에서 가려야 할 채팅 영역을 표시        |
| `/live full`    | 플레이어 ID와 채팅 내용을 숨깁니다                              |
| `/live off`     | 방송 프라이버시 모드를 끕니다                                   |

## 기타

| 명령어                       | 설명                                                 |
| ---------------------------- | ---------------------------------------------------- |
| `/help`                      | 등록된 명령어 목록 표시                              |
| `/clear`                     | 콘솔 표시 내용 비우기                                |
| `/whereami`                  | 낮 장면에서 현재 맵과 좌표 표시                      |
| `/get currentactivemaplabel` | 현재 맵 이름 표시                                    |
| `/get pos`                   | 현재 위치 표시                                       |
| `/link MetaMystia`           | MetaMystia 저장소 열기                               |
| `/link Izakaya`              | 동방 야작식당 도우미 열기                            |
| `/call try_close_izakaya`    | 마감 흐름이 멈췄을 때 로컬 영업을 강제로 끝내기 시도 |

`/debug` 및 기타 `/call` 하위 명령어는 개발과 진단용입니다. 게임 상태를 직접 바꿀 수 있으므로 일반 플레이어에게는 권장하지 않습니다.
