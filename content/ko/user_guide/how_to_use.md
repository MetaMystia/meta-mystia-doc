# 사용 방법

이 페이지에서는 MetaMystia를 설치한 뒤 게임에서 해야 할 기본 조작과 멀티플레이 진행 방법을 설명합니다.

컴퓨터 네트워크나 '명령어'라는 개념이 익숙하지 않아도 걱정하지 마세요. 단계대로 따라 하면 친구와 함께 접속해 플레이할 수 있습니다.

시작하기 전에 모든 플레이어가 MetaMystia를 설치하고 게임 메인 메뉴에 한 번 이상 들어가 있어야 합니다. ResourceEx 확장 콘텐츠를 사용한다면 같은 버전의 리소스 팩도 설치해야 합니다.

## 접속 방식 선택

MetaMystia는 두 가지 멀티플레이 방식을 지원합니다:

| 방식      | 적합한 상황                                                 | 주요 명령어                          |
| --------- | ----------------------------------------------------------- | ------------------------------------ |
| 서버 모드 | 같은 LAN이 아니고 네트워크 도구 설정도 하고 싶지 않은 경우  | `/mp play`, `/mp create`, `/mp join` |
| LAN 모드  | 같은 LAN이거나 Tailscale 등으로 이미 네트워크를 구성한 경우 | `/mp start`, `/mp connect`           |

두 방식의 플레이 흐름은 같고, 방을 만들고 참가하는 단계만 다릅니다.

## 준비: 플레이어 이름 설정

모든 플레이어가 <kbd>/</kbd>를 눌러 명령어 입력창을 열고 다음을 입력합니다:

```text
/mp id PlayerName
```

`PlayerName`은 다른 플레이어에게 표시되는 이름이며 자신의 이름으로 바꾸면 됩니다. 이름에는 공백을 넣을 수 없고, 방 안의 다른 플레이어와 중복되어도 안 됩니다. 설정하지 않으면 컴퓨터 이름이 사용됩니다.

## 서버 모드 {#server_mode}

### 방 만들기

한 명이 테스트 멀티플레이 서버에 접속해 방을 만듭니다:

```text
/mp play
/mp create 4
```

`4`는 방을 만든 플레이어를 포함한 최대 인원입니다. 실제 인원에 맞게 수정하세요. 생성에 성공하면 콘솔에 `AB20` 같은 4자리 방 번호가 표시됩니다. 이 번호를 다른 플레이어에게 알려 주세요.

### 방 참가

다른 플레이어는 다음을 입력합니다:

```text
/mp play
/mp join AB20
```

`AB20`을 실제 방 번호로 바꾸세요. 대소문자는 모두 가능합니다. 번호를 모른다면 서버에 접속한 뒤 `/mp rooms`를 입력해 서버의 방 목록을 볼 수 있습니다.

### 방 나가기

`/mp leave`를 입력하면 현재 방에서 나가면서도 서버 연결은 유지되므로, 이후 다시 방을 만들거나 다른 방에 참가할 수 있습니다. 방을 만든 플레이어가 나가면 방은 해산되고, 다른 플레이어들은 방에서 나오지만 서버에는 연결된 상태로 남습니다.

`/mp disconnect`를 입력하면 서버 연결이 완전히 끊어집니다.

## LAN 모드

### 1단계: 방 인원 설정

방은 기본적으로 최대 2명(방장 포함)입니다. 3명 이상 플레이할 때는 방장이 다음을 입력합니다:

```text
/mp maxplayers 4
```

위의 `4`는 방의 최대 인원입니다. 실제 인원에 맞게 수정하세요.

### 2단계: 방장이 방 열기

방장은 다음을 입력합니다:

```text
/mp start
```

`/mp start`를 실행한 뒤 방장은 자신의 IP 주소를 다른 플레이어에게 알려야 합니다. 모두가 같은 LAN에 있지 않다면 Tailscale, ZeroTier 같은 네트워크 도구를 먼저 사용하고, 그 도구에 표시되는 IP를 알려 주세요. 대신 [서버 모드](#server_mode)를 사용할 수도 있습니다.

### 3단계: 다른 플레이어 참가

참가하는 플레이어는 각각 다음을 입력합니다:

```text
/mp connect 방장IP
```

예:

```text
/mp connect 192.168.1.10
```

접속하면 방장의 방에 자동으로 들어갑니다. 방장이 종료하면 멀티플레이가 끝나므로 방을 다시 열어야 합니다.

## 플레이 진행

접속에 성공하면 <kbd>Enter</kbd>를 눌러 플레이어 목록을 열 수 있습니다. 목록에는 방장, 다른 플레이어, 그리고 각자 현재 진행 중인 게임 단계가 표시됩니다.

> [!NOTE]
> 방 안의 모든 플레이어가 메인 메뉴 또는 낮에 있고 방장이 아직 낮을 끝내지 않았을 때만 다른 플레이어가 참가하거나 다시 접속할 수 있습니다. 메인 메뉴나 낮 시간에 모든 플레이어를 모은 뒤 진행하세요.

- 낮: 각자 자신의 세이브 파일로 낮 활동을 진행합니다. 모든 플레이어가 낮을 마쳐야 다음으로 넘어갑니다.
- 가게 선택: 모든 플레이어가 같은 가게와 등급을 선택해야 합니다.
- 개점 전: 각자 메뉴, 음료, 조리 도구를 선택하고, 전원이 확인해야 영업이 시작됩니다.
- 영업: 요리, 재료 가져오기, 서빙, 손님 응대를 나눠 할 수 있습니다.

중간에 누군가 나가면 남은 플레이어들이 현재 흐름을 마친 뒤 자동으로 계속합니다. 개점 전 설정이 대기 화면에서 멈춰 있다면, 방장이 자신의 설정을 확인한 뒤 다음을 입력할 수 있습니다:

```text
/mp continue prep
```

실행하면 모든 플레이어가 확인한 것으로 처리되어 바로 영업이 시작됩니다.

## 채팅과 플레이어 목록

아래는 MetaMystia의 기본 키입니다. 모드 설정을 수정했다면 본인의 설정이 우선입니다.

| 키                          | 기능                                                                  |
| --------------------------- | --------------------------------------------------------------------- |
| <kbd>T</kbd>                | 채팅 입력창 열기                                                      |
| <kbd>/</kbd>                | 명령어 입력창 열기                                                    |
| <kbd>Enter</kbd>            | 입력창이 닫혀 있으면 플레이어 목록 표시/숨기기, 열려 있으면 내용 전송 |
| <kbd>Esc</kbd>              | 입력창 닫기                                                           |
| <kbd>&#92;</kbd>            | 왼쪽 아래 상태 문구 표시/숨기기                                       |
| <kbd>Tab</kbd>              | 명령어 자동 완성                                                      |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 이전에 입력한 명령어 확인                                             |

채팅은 그대로 입력하면 되고, `/`로 시작하는 내용은 명령어로 실행됩니다. 플레이어 목록과 채팅 창은 드래그해 위치를 옮길 수 있습니다.

## LAN 모드에서의 네트워크 연결

네트워크 설정이 번거롭다면 [서버 모드](#server_mode)를 바로 사용할 수 있습니다.

- 같은 Wi-Fi 또는 LAN: 방장의 LAN IP를 사용합니다.
- 다른 네트워크: Tailscale, ZeroTier 같은 도구로 모든 플레이어를 하나의 가상 LAN에 넣습니다.
- 방장에게 공인 IP가 있는 경우: 방화벽과 공유기에서 포트를 열면 직접 접속할 수 있습니다.

MetaMystia는 기본적으로 `40815` 포트를 사용합니다. 변경할 때는 방장과 다른 플레이어 모두 같은 포트를 사용해야 합니다:

```text
/mp start 50000
```

다른 플레이어는 다음 중 하나의 형식으로 입력합니다:

```text
/mp connect 192.168.1.10:50000
/mp connect 192.168.1.10 50000
```

일반적으로 IPv6 설정을 바꿀 필요는 없습니다. IPv6 네트워크를 실제로 사용한다면 [자주 쓰는 명령어](./commands.md)에서 관련 명령어를 확인하세요.

## 접속되지 않을 때

차례대로 확인하세요:

1. 모든 사람이 같은 버전의 게임과 MetaMystia를 설치했는지.
2. 모두 메인 메뉴에 한 번 이상 들어갔고, 왼쪽 아래에 MetaMystia 상태 문구가 보이는지.
3. 서버 모드에서 모두 `/mp play`로 접속에 성공했고 방 번호가 올바른지.
4. LAN 모드에서 방장이 `/mp start`를 입력했고, 다른 플레이어가 입력한 IP와 포트가 올바른지.
5. 방 인원이 가득 찼는지, 이름이 중복되거나 공백을 포함하지 않는지.
6. 방 안에 이미 개점 전 설정에 들어갔거나 영업을 시작한 플레이어가 있는지, 또는 방장이 낮을 끝냈는지.
7. 방화벽, 공유기, 네트워크 도구가 접속을 막고 있지 않은지.

`/mp status`를 입력하면 현재 접속 상태를 확인할 수 있습니다. 그래도 해결되지 않으면 [자주 묻는 질문](./faq.md)을 확인하세요.

## 도움받기 {#get_help}

[GitHub Issues](https://github.com/MetaMystia/MetaMystia/issues)로 문제를 알릴 수 있습니다. 원인 파악을 위해 다음 정보를 제공해 주세요:

- 문제 증상과 조작 단계;
- 모든 플레이어의 게임, MetaMystia, DLC, 리소스 팩 버전;
- 오류 화면 캡처;
- 모든 플레이어의 `게임 루트 폴더/BepInEx/LogOutput.log`;
- 사용하는 네트워크 방식(같은 LAN, Tailscale, 포트 포워딩 등).

관리 도구를 사용한다면 도구가 내보내는 진단 패키지를 첨부할 수 있습니다. 도구를 실행한 뒤 '작업 선택' 페이지에서 **진단 패키지 내보내기**를 선택하고 안내에 따라 내보내세요. 내보내기가 끝나면 압축 파일 경로가 표시되며, '폴더 열기'를 눌러 바로 찾아갈 수도 있습니다.
